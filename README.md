# Кто Я — Локальный Ассистент для Linux

> *"Я не человек. Я не имя. Я идея."*  
> Вдохновлён фильмом *Кто Я (2014)*.

Это локальный анонимный помощник с ИИ, голосовым вводом и выводом. Работает на Linux (Debian-based).

---

## ✅ Возможности

- Голосовой ввод (через Vosk)
- Голосовой вывод (через Silero TTS)
- Управление системой: браузер, Wi-Fi, выключение и др.
- Поддержка ИИ через Ollama
- Современный GUI на PyQt5

---
